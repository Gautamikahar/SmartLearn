# SmartLearn

SmartLearn is a full-stack Learning Management System (LMS).

## Tech Stack

### Frontend
- React
- Vite
- React Router
- Redux Toolkit
- Axios

### Backend
- Node.js
- Express.js
- MongoDB
- Mongoose
- JWT
